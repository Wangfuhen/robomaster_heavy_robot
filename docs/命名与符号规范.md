# 底盘命名与符号规范

| 项目 | 内容 |
|---|---|
| 依据 | `项目资料/hero_gimbal` 的命名与符号规范 |
| 范围 | `chassis_task`、`can_user`、底盘相关任务引用 |
| 更新时间 | 2026-11-12 |

## 1. 常量

- 不再使用 `#define` 配置常量（只保留 include guard）；
- 全部放进 `balance_application/all_task/chassis_configuration.h`；
- 使用 `static const` + 明确类型；
- 名字带单位后缀：`_millisecond`、`_radian`、`_radian_per_second`、`_revolution_per_minute`、`_watt`、`_ampere`、`_meter`、`_count`、`_volt`。

示例：

```c
static const float chassis_speed_loop_proportional_gain = 20.0f;
static const float chassis_forward_speed_maximum_remote_control_revolution_per_minute = 3300.0f;
static const uint32_t chassis_control_loop_period_millisecond = 2U;
```

原来的 `CHASSIS_SPEED_PID_P`、`CHASSIS_SPEED_MAX_VX_DT7`、`BUFFER_PID_*`、`K0..K5`、`RPM_RADS`、`MA_A`、`LPF_CHASSIS_*`、`SLOPE_CHASSIS_*`、`YAW_*`、`MOTOR_ECD_TO_RAD` 等全部改名并迁入该头文件。

## 2. 类型与字段

- 类型用 `_t` 结尾，去掉拼写错误和缩写；
- 字段用名词结尾，带单位；
- 不使用 `vx/vy/wz/ecd/rpm/pid/msg` 这类缩写（`CAN`、`PID`、`IMU`、`RC` 等协议/外设缩写保留）。

| 原 | 现 |
|---|---|
| `chassi_mode_e` | `chassis_operating_mode_e` |
| `cap_mode_e` | `super_capacitor_mode_e` |
| `top_mode_e` | `top_spin_mode_e` |
| `chassis_motor_t` | `chassis_motor_state_t` |
| `chassis_follow_change_t` | `chassis_follow_gimbal_transition_t` |
| `motor_measure_t` | `motor_measurement_t` |
| `super_cap_t` | `super_capacitor_measurement_t` |
| `chassis_c_get_data_t` | `gimbal_command_data_t` |
| `vx_now` | `forward_speed_revolution_per_minute` |
| `vy_now` | `leftward_speed_revolution_per_minute` |
| `wz_now` | `rotation_speed_radian_per_second` |
| `relative_angle` | `gimbal_relative_angle_radian` |
| `give_current` | `commanded_torque_current_count` |
| `speed_rpm` | `rotor_speed_revolution_per_minute` |

## 3. 函数

- 函数统一 `Chassis_动词名词`，静态函数也遵守；
- 不再使用 `chassis_init`、`chassis_update_feedback` 这类全小写、动词不突出的写法。

| 原 | 现 |
|---|---|
| `chassis_init` | `Chassis_Initialize` |
| `chassis_parse_mode` | `Chassis_ParseOperatingMode` |
| `chassis_update_feedback` | `Chassis_UpdateFeedback` |
| `chassis_set_target_speed` | `Chassis_SetSpeedSetpoint` |
| `chassis_run_speed_pid` | `Chassis_CalculateSpeedControlOutput` |
| `chassis_calc_target_speed` | `Chassis_CalculateSpeedSetpoint` |
| `chassis_power_limit` | `Chassis_ApplyPowerLimit` |
| `chassis_vector_to_wheel_speed` | `Chassis_ConvertVectorToWheelSpeed` |
| `motor_encoder_to_angle` | `Chassis_ConvertEncoderCountToAngleRadian` |

## 4. 宏清理

删除的宏：

- `Remote_Deadband_Limit`、`Limit_Max`、`Abs`、`Sqrt`（函数式宏）；
- `get_motor_measure`、`get_gimbal_measure`、`get_cap_measure`（CAN 解析宏，改为 `CAN_Parse*` 静态函数）；
- `gimbal_can` / `chassis_can` 别名（直接使用 `hcan1` / `hcan2`）；
- `chassis_task.h` 中约 90 行配置宏。

`can_user.c` 的 CAN 解析宏改成：

```c
static void CAN_ParseChassisMotorMeasurement(motor_measurement_t *measurement, const uint8_t *payload);
static void CAN_ParseGimbalCommand(gimbal_command_data_t *command, const uint8_t *payload);
static void CAN_ParseSuperCapacitorMeasurement(super_capacitor_measurement_t *measurement, const uint8_t *payload);
```

## 5. 符号约定

- 底盘前进为正（`forward`）；
- 左移为正（`leftward`）；
- 逆时针自旋为正（`rotation`）；
- 电机电流以 C620 的 `±16384` 计数为单位，字段统一 `_count`；
- 功率/电压/电流在字段名上带 `_watt` / `_volt` / `_ampere`。

## 6. 验证

- `chassis_task.c`、`can_user.c`、`referee_usart_task.c`、`ui_task.c`、`debug_task.c` 已用 `arm-none-eabi-gcc -fsyntax-only` 检查通过；
- `ins_task.c` 的报错来自本地 CMSIS-RTOS2 shim 缺少 `osThreadFlags*`，不是本次改名引入；
- 没有 Keil 编译，最终以 Keil 构建为准。
